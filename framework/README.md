# slendie/framework

> Repositório **espelho só de leitura**, gerado a partir de [`slendie/monorepo`](https://github.com/slendie/monorepo) (pasta `framework/`).
> Issues e pull requests: no monorepo.

O código da [Slendie](https://slendie.lcloss.dev) v4: um "Laravel light" em PHP 8.5, sem dependências em runtime — MVC, Blade
compilado, Query Builder, Models, migrações e CLI (`php slendie`).

Normalmente não se instala directamente; usa o skeleton:

```bash
composer create-project slendie/slendie meu-site
```

Packages opcionais: `slendie/auth` (autenticação) e `slendie/react-admin` (painel de leads em React).
Documentação: <https://slendie.lcloss.dev/docs>.
